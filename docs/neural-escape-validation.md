# FlyMind: исследование ответа Giant Fiber

Ответ GF воспроизведён **в вычислительной модели**, без прямой стимуляции GF,
обучения или изменения биологических связей. **Биологическая валидация не завершена.**
Основная причина тишины исходного PoC — политика знаков, обнулявшая большую долю
прямых входов LC4/LPLC2. Изменение только этой политики уже даёт спайки GF при прежних
масштабе синаптического влияния, стимулах и мембранных параметрах.

Работа выполнена в `feat/flymind-neural-poc`. Предыдущие незакоммиченные изменения
сохранены; production Canvas Pusher, Supabase, webhook и workflow не изменены.
Push, deploy, Telegram-интеграция и dashboard не выполнялись.

После возобновления сессии 14 октября 2026 года заново выполнены все **23 опыта**,
включая расширенный граф, и полный набор тестов: **66 passed, 0 skipped,
172 warnings, 24,44 s**. Хэши полной нейронной активности и пяти файлов расчётного
кода во всех 23 опытах совпали с сохранёнными результатами предыдущей сессии.
Каждый новый JSON.gz повторно прочитан: потенциалы конечны, прямой стимуляции GF
нет, `biological_response_validated=false`. Данные и модель после возобновления
не менялись; добавлены свежие экспорты и запись проверки.

Запись сверки: [neural-escape-resume-verification.json](neural-escape-resume-verification.json).
Полный новый suite: `data/neural/runs/escape-resumed-20261014/escape-suite.json`;
рядом находятся отдельные JSON.gz с событиями и трассами.
Новые локальные медианы CPU / whole-subprocess wall и максимальный peak RSS
по трём повторам: baseline **1,661 s / 2,051 s / 215,875 МиБ**,
weak **1,641 s / 2,123 s / 217,078 МиБ**,

## Причина тишины и источники предположений

В исходном PoC знак брался из `nt_type` **строки связи**. GLU/DA/SER/OCT давали нуль.
Но все LC4 и LPLC2 имеют `known_nt=acetylcholine`, `known_nt_source=Davis et al., 2020`;
в каталоге нейронов 311 из 314 также предсказаны как ACh, а у трёх prediction пустой.
Это конфликт предсказаний и клеточной аннотации, а не основание переписать данные.

Следствия старой политики для прямых входов GF:

- Слева только **253 / 634** контакта были возбуждающими; потенциальный синхронный
  одиночный пакет давал **5,06 mV** вместо 12,68 mV при клеточной ACh-интерпретации.
- Справа **243 / 967** возбуждающих, ещё 13 помечены GABA; подписанный пакет давал
  **4,60 mV** вместо 19,34 mV.
- Старый порог был на 15 mV выше rest; фактические максимумы деполяризации GF,
  измеренные перед проверкой порога через 0,1 ms: **6,885 / 6,801 mV**. Порог не достигнут.

Новая политика интерпретирует известный медиатор клеточного типа при наличии ссылки,
затем использует whole-neuron prediction; неизвестный остаётся неизвестным.
Сырые поля `nt_type`, `predicted_nt`, `known_nt` не изменяются. Нет оснований утверждать,
что все противоречащие edge-предсказания ошибочны, или что клеточная аннотация задаёт
рецептор и знак каждой конкретной связи.
[Davis et al., eLife 2020](https://doi.org/10.7554/eLife.50901) описывает транскриптомный
ресурс; холинергическая интерпретация опирается на клеточные аннотации этого источника.

Проверка только политики знаков, **без изменения остальных параметров**:

- `legacy_raw`: 988 спайков, 340 активных клеток, GF **0 / 0**.
- `legacy_presynaptic`: 1 001 спайк, 346 активных клеток, GF **1 / 3**.
  Первые спайки GF: 51,5 и 34,9 ms, стимул начинался в 20 ms.

Таким образом, отсутствие прямых LC4/LPLC2 → GF не объясняет исходную тишину.
Непоследовательная трактовка медиаторов достаточна для объяснения в данном PoC.
Это не доказывает, что новая политика точно воспроизводит биологию.

## Опубликованный вариант динамики и стимулы

Legacy-профиль сохранён. Отдельно реализован generic LIF по параметрам
[Shiu et al., Nature 2024](https://doi.org/10.1038/s41586-024-07763-9) и
[закреплённому коду авторов](https://github.com/philshiu/Drosophila_brain_model/blob/91bdd1e7dcf193f3e7ca5a8933497fcef63b7960/model.py):

```text
dv/dt = (Vrest - v + g + drive) / tau_m
dg/dt = -g / tau_s
spike при v >= Vthreshold; reset v и g; refractory
после задержки: g += syn_count * weight_per_synapse * sign
```

Rest/reset `-52 mV`, threshold `-45 mV`, `tau_m=20 ms`, `tau_s=5 ms`, refractory
`2,2 ms`, delay `1,8 ms`. `0,275 mV` — **свободный параметр опубликованной модели**,
вводимый в затухающий `g`, а не измеренный EPSP и не скачок мембранного потенциала.
Аналитический тест одиночного контакта даёт пик EPSP модели около **0,04331 mV**.
Динамика интегрируется точно между событиями; шаг обнаружения спайков — 0,1 ms.
Во время refractory `v` и `g` фиксированы, входящие изменения игнорируются;
после спайка `g` сбрасывается. Эти параметры не являются измерениями выбранных GF.

Основной вариант `presynaptic_shiu`: ACh/DA/SER/OCT положительные, GABA/GLU отрицательные,
неизвестные — нуль. Это опубликованная модельная конвенция, а не доказательство
полярности модуляторов. `presynaptic_conservative` оставляет GLU и модуляторы нулевыми;
`edge_prediction` сохраняет старую политику. Все варианты держат те же биологические строки.

[Ache et al., 2019](https://doi.org/10.1016/j.cub.2019.01.079) мотивирует разделение
LC4/скорость и LPLC2/размер. Геометрия диска соответствует используемым в
[Jang et al., 2023](https://doi.org/10.1242/jeb.244790) looms 10–63° и r/v 20/80 ms:

```text
theta(t) = 2 atan((r/v) / time_to_collision)
LC4 drive ~ contrast * angular_velocity / 2000 deg/s
LPLC2 drive ~ contrast * Gaussian(theta; preference 60°, width 15°)
```

Gain 30 mV, Gaussian preference/width, contrast-to-drive mapping и однородное
возбуждение всей популяции — **явные, не подогнанные предположения**. Генерируются
детерминированные voltage-equivalent drive-профили с sampling 1 ms. Это не
измеренные токи в pA, не модель сетчатки/рецептивных полей и не калиброванный visual input.

Все основные опыты идут 1 100 ms, начинаются с rest, стимул начинается в 100 ms;
GF никогда не входит в stimulus IDs. По три отдельных процесса на условие:

- **Baseline:** contrast 0, 0 спайков, 0 активных клеток, GF **0 / 0**.
- **Weak:** contrast 0,35, r/v 80 ms, expansion до 883,856 ms. Пик LC4 drive
  **2,034 mV**, LPLC2 **10,500 mV**. LC4: 0 спайков, LPLC2: 254.
  Всего **344 спайка / 282 активные клетки**. GF **2 / 2**, первые спайки
  **851,1 / 850,0 ms** (latency от начала 751,1 / 750,0 ms).
- **Strong:** contrast 1, r/v 20 ms, expansion до 295,964 ms. Пик LC4 drive
  **22,483 mV**, LPLC2 **30,000 mV**. LC4: 208 спайков, LPLC2: 419.
  Всего **834 / 418**. GF **3 / 4**, первые спайки **279,8 / 279,6 ms**
  (latency 179,8 / 179,6 ms).

Weak медленнее и дольше: интеграл LPLC2 drive в нём **1 057,36 mV·ms**, а в Strong
**744,23 mV·ms**; интегралы LC4 соответственно 277,55 и 784,51 mV·ms. Поэтому один
contrast не задаёт суммарный вход, а число спайков нельзя трактовать как чистую шкалу
"силы угрозы" без учёта длительности и скорости.

## Контроли, чувствительность и ограничения ответа

Всего основной suite содержит **23 запуска** (14 конфигураций исходного графа,
повторы трёх основных условий и три запуска расширенного графа):

- Слабый contrast 0,35 при той же быстрой геометрии, что Strong (`weak_fast`):
  **0 спайков**. Длинная интеграция важна для Weak, а не только амплитуда.
- Strong contrast 1 с медленной геометрией (`strong_slow`): **2 032 спайка**,
  GF **9 / 13**. Более долгое возбуждение даёт больше спайков; быстрый стимул
  не обязан выигрывать по общему числу событий.
- Strong с нулевыми синаптическими весами: зрительные клетки дают **838 спайков**,
  но обе GF остаются в rest, без спайков/деполяризации. Ответ GF требует связности.
- Только LC4 drive: **286** спайков, GF **2 / 2**, LPLC2 не даёт спайков.
  Только LPLC2 drive: **564**, GF **3 / 3**, LC4 не даёт спайков.
  Это исключение одного входного drive, не генетическое silencing клеток/выходов.
- Strong, консервативная NT-политика: **876**, GF **4 / 5**; raw-edge политика:
  **850**, GF **3 / 5**. Точные выходы зависят от неподтверждённой полярности.
- Шаг 0,05 ms: Strong **833** вместо 834 спайков, GF по-прежнему **3 / 4**;
  первый спайк каждой GF сдвигается на 0,05 ms, один поздний — на 1,8 ms.
  Полные spike trains не объявляются сошедшимися. Weak остаётся 344 и **2 / 2**.
- Расширенный граф: legacy остаётся **988**, GF **0 / 0**. Weak **347 / 285**,
  GF **2 / 2**; Strong **838 / 422**, GF **3 / 4**. Числа спайков GF сохранены,
  но поздние времена отличаются (Strong справа последний 313,6 вместо 310,3 ms).
  Потерянные входы важны для количественного тайминга, хотя не объясняют исходную тишину.

Модель не воспроизводит всё экспериментальное поведение. В частности, LC4-only
drive активирует GF без спайков LPLC2, тогда как Ache et al. сообщают о необходимости
LPLC2 для GF-mediated escape в своих условиях. Протоколы не совпадают, поэтому это
не прямое опровержение, но запрещает объявлять модель биологически валидированной.
Нет ретинотопики, специфических GF-параметров, адаптации/пространственного рекрутирования,
подтверждённых рецепторов, электрических синапсов, VNC/мышц или behavioral output.

Альтернативный readout — **baseline-subtracted GF membrane depolarization и время её
пика**, используемые в электрофизиологическом анализе Jang et al. Он полезен при
субпороговом ответе, когда spike/no-spike недостоверно из-за предполагаемого порога.
В LIF надпороговый пик ограничен threshold/reset и включает численный overshoot;
его нельзя сопоставлять с амплитудой настоящего action potential. Для таких режимов
следует показывать spike count, first latency и всю модельную трассу.

## Проверки, экспорты и benchmark

Baseline перед изменениями: **49 passed**. Полный финальный suite: **66 passed,
172 warnings, 24,96 s**. Warnings идут из deprecated
вызовов pyparsing в Brian2, не из расчётных ошибок.
Проверены аналитическое EPSP-ядро, directed paths, неизменность исходных CSV,
расширение и полный source-аудит, NT provenance, запрещённая стимуляция GF,
детерминизм, конечность потенциалов, контроль zero-synapses, шаг интеграции и offline export.
С cache проверки источников выполняются; без cache source/expansion тесты явно пропускаются.

`neural-escape-results.json` — 23 запуска, параметры/профили, популяционные активности,
readout, arrival budgets, хэши активности/кода, benchmark и источники.
Полные JSON.gz с каждым spike и GF traces находятся в указанном в каждом run поле
`output` под `data/neural/runs/`; эти файлы намеренно игнорируются Git, но уже созданы
локально и воспроизводятся CLI. IDs — строки, времена — ms; абсолютное время создания UTC.
Arrival budgets — предполагаемые суммы доступных g-increments до refractory losses/decay,
не измеренные EPSP и не фактическая деполяризация.

Статические научные рисунки — `neural-escape-figures/escape-response.{png,svg}` и
`transmitter-policy.{png,svg}`. Это экспорт результатов, не Neural Observatory/dashboard.

Измерения — macOS ARM64, Python 3.11.17; NumPy/Brian2, matplotlib 3.11.2 установлен;
численные библиотеки ограничены одним потоком. Отдельный процесс на запуск, cache ОС
и шрифтов прогрет. Внутренние CPU/RSS включают загрузку, импорт, симуляцию и экспорт,
но исключают последующий анализ/построение графиков. Whole-subprocess wall включает
derived metrics и вывод summary. Точные финальные числа — в JSON benchmark;
Baseline: **1,491 s CPU / 1,847 s wall / 215,828 МиБ peak RSS**.
Weak: **1,659 s / 2,015 s / 216,813 МиБ**.
Strong: **1,598 s / 1,962 s / 217,109 МиБ**.

Независимая проверка полного CLI через `/usr/bin/time -l`: **2,35 s wall**,
**1,89 s user + 0,19 s system CPU**, **219,078 МиБ maximum RSS**. Эти данные
сохранены в `neural-escape-external-benchmark.json`. Замер сделан до компактного
финального повторения suite; это отдельное наблюдение, не медиана.

На Linux GitHub Actions измерений ещё нет; короткий Python batch worker выглядит
реалистично. Прямой запуск Brian2 в Supabase Deno Edge по-прежнему не реализован;
лимит CPU 2 s/request также требует осторожности при будущей оркестрации.

## Воспроизведение

Из корня, в существующей Python 3.11 среде:

```bash
.venv/neural/bin/python -m pytest -q --tb=short --disable-warnings --show-capture=no
.venv/neural/bin/python -m src.neural.escape case --case legacy_presynaptic --output data/neural/runs/nt-policy-demo.json.gz
.venv/neural/bin/python -m src.neural.escape case --case strong --output data/neural/runs/strong-demo.json.gz
.venv/neural/bin/python -m src.neural.escape suite --output-dir data/neural/runs/new-escape-suite
```

На чистом checkout: `python3.11 -m venv .venv/neural`, затем
`.venv/neural/bin/python -m pip install -r requirements.txt -r requirements-neural-validation.txt`.
Matplotlib нужен только для рисунков; simulation/tests работают с `requirements-neural.txt`.

Для воспроизведения source-аудита и расширения сначала заполнить закреплённый cache:

```bash
.venv/neural/bin/python -m src.neural.ingest --output data/neural/cache/rebuilt-for-escape
.venv/neural/bin/python -m src.neural.connectivity --output data/neural/runs/new-connectivity.json --expand-output data/neural/cache/new-gf-boundary
.venv/neural/bin/python -m src.neural.escape suite --output-dir data/neural/runs/new-boundary-suite --expanded-connectome data/neural/cache/new-gf-boundary
.venv/neural/bin/python -m src.neural.plot_escape --suite data/neural/runs/new-boundary-suite/escape-suite.json --output-dir data/neural/runs/new-boundary-suite/figures
```

Все пути результатов должны быть новыми; перезапись не выполняется. Нужны только
небольшие публичные закреплённые source-файлы, без credentials и multi-GB synapse dump.

Следующий научный шаг — получить/оцифровать GF и LC4/LPLC2 time courses под совпадающим
visual protocol, определить допустимый recruitment/feature-to-drive transfer и
проверить GF depolarization/latency и LPLC2 dependence по заранее заданным критериям.
Физиологические параметры стоит устанавливать по независимым данным, а не выбирать
ради появления спайков. До этого к dashboard/Telegram переходить преждевременно.
